# Embedded Presentation

You can also view the presentation directly below.

> NOTE:  
> To display properly on GitHub Pages or Markdown-supported websites, the presentation must be published to the web.

## Step 1 — Publish Google Slides to Web

In Google Slides:

1. Open the presentation
2. Click **File**
3. Select **Share**
4. Choose **Publish to web**
5. Open the **Embed** tab
6. Click **Publish**
7. Copy the generated embed link

Google officially supports publishing and embedding Slides presentations. :contentReference[oaicite:0]{index=0}

# HTML Embed Code

Replace `YOUR_EMBED_LINK` with your published embed URL.

```html
<iframe 
    src="YOUR_EMBED_LINK"
    frameborder="0"
    width="960"
    height="569"
    allowfullscreen="true"
    mozallowfullscreen="true"
    webkitallowfullscreen="true">
</iframe>


Important:  
GitHub .md files usually block live iframe rendering for security reasons. The iframe will work properly on:

- GitHub Pages
- Personal websites
- Documentation sites
- Static hosting platforms

But in normal GitHub repository README view, users may only see the HTML code instead of the embedded slide.
